# Vimd 演示

这是一个独立 Rust 实现的终端 Markdown 阅读器，支持 **粗体**、*斜体*、`行内代码`、
[链接](https://example.com) 和图片 ![终端图标](demo.png)。

## 为什么不用放大字号？

> 终端是固定单元格网格。字号不能逐行改变，但颜色、字重和标题装饰线可以。

### 功能列表

- 阅读态：隐藏 Markdown 标记
- 编辑态：按 `i` 显示源码和行号
  - 嵌套列表也保留缩进
- [ ] 字号不能逐行设置
- [x] 颜色和字重可以设置

### 代码

```rust
// 代码块用圆角盒子包起来
fn main() {
    println!("hello, vimd");
}
```

### 表格

| 能力 | 状态 | 说明 |
| :--- | :---: | ---: |
| 标题颜色 | 支持 | 设置页 |
| 表格框线 | 支持 | 圆角 |
| 逐行字号 | 不支持 | 终端限制 |

---

### 小标题

正文继续。按 `F2` 进入设置页，按 `Esc` 回到阅读态，按 `i` 编辑，`:wq` 保存退出。
